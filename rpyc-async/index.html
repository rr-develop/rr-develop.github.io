rpyc-async

An asyncio-native fork of RPyC (Remote Python Call), a library for symmetric remote procedure calls between Python processes. The fork adds native async/await support: async services, async clients and bidirectional async callbacks driven by a persistent event loop.

Relationship to upstream RPyC

rpyc-async is forked from RPyC 6.0.1 and versioned independently (current release 1.1.0). It is a separate distribution, not a drop-in replacement for classic synchronous RPyC: the API centres on async_connect() and AsyncioServer, and both peers must run rpyc-async. The distribution name is rpyc-async; the import name is rpyc_async. Both can be installed in the same environment as upstream rpyc.

Installation

pip install rpyc-async

Requires Python 3.10 or later. The PyPI classifiers list Linux and POSIX as the operating systems.
