deep-worker

An AI agent framework for running LLM agents as local background processes and interacting with them through a terminal CLI. Agents run as daemon processes, persist conversation history, and are driven interactively with dwcli.

deep-worker is a fork and continuation of deepagents-cli.

Components

  • Core agent runtime: the deep-worker daemon and the dwcli interactive client.
  • Providers: Claude Code SDK, OpenAI Codex CLI and xAI Grok CLI backends.
  • dw-hist: a host-level command for semantically browsing agent conversation history.
  • Optional LSP code navigation for agents, and semantic search over history.
  • A local web UI bound to 127.0.0.1.

Notable features

  • External MCP tools, with layered configuration.
  • A2A protocol support for agent-to-agent interoperability.
  • An inter-agent messaging tool with replies.
  • Automatic context summarization and a delta checkpointer.

Installation

pip install deep-worker

The PyPI package lists Python 3.11 or later and is an early release (development status: Beta). The repository's README describes running from a source checkout; its quick start is the reference for the current setup.
