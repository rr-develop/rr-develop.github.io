rpyc-async

An asyncio-native fork of RPyC for reliable and efficient asynchronous inter-process calls. Forked from RPyC 6.0.1; MIT licence; Python 3.10 and later.

deep-worker

An AI agent framework for running LLM agents as local background processes, driven interactively through a terminal CLI (dwcli). MIT licence; Python 3.11 and later.

  • Source: github.com/rr-develop/deep-worker
