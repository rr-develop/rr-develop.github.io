rpyc async: asyncio RPC for Python

rpyc-async (import name rpyc_async) is an asyncio-native fork of RPyC, the Python library for calling objects in other processes. You call remote methods with await. It is a young project: the repository was created in July 2026, it is in active development, and it is forked from RPyC 6.0.1. It already runs inside the agent processes of deep-worker.

What it gives you

  • Callbacks in both directions. The server can call back into an idle client and get an answer.
  • async and await on both sides. Many calls can wait at once on one connection, without a thread for each.
  • Quiet when idle. On the asyncio API, an idle connection wakes nothing up.
  • Remote objects released when you let go. On the asyncio API, the server releases a remote object when your last reference to it goes away. Releases are batched and confirmed by the server.

Quick start

pip install rpyc-async

Server:

import asyncio
from rpyc_async import AsyncioServer, Service

class MyService(Service):
    async def exposed_double(self, x):
        await asyncio.sleep(0.1)
        return x * 2

async def main():
    server = AsyncioServer(MyService, port=18871)
    await server.start()
    await asyncio.sleep(8)

asyncio.run(main())

Client, run while the server is up. It prints 42:

import asyncio
import rpyc_async as rpyc

async def main():
    conn = await rpyc.async_connect("localhost", 18871)
    try:
        print(await conn.root.double(21))
    finally:
        await conn.aclose()

asyncio.run(main())
